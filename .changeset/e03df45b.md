feat(rds): generate IAM authentication tokens for database connections

RDS and Aurora databases can take a short-lived IAM token instead of a password. `generate_db_auth_token` returns one for a host, port and database user. It is signed locally with the client's credentials and region, so nothing is sent to AWS.

```python
import asyncpg
from capo_rds import AsyncRDSClient

HOST = "mydb.123456789012.us-east-1.rds.amazonaws.com"

async with AsyncRDSClient(region="us-east-1") as rds:
    token = await rds.generate_db_auth_token(hostname=HOST, port=5432, username="app")

# The token is the password. IAM authentication needs TLS
conn = await asyncpg.connect(
    host=HOST, port=5432, user="app", password=token, database="postgres", ssl="require"
)
```

A token is valid for 15 minutes, but a connection opened with it stays open. The credentials need the `rds-db:connect` permission, and the database user has to be set up for IAM authentication. The sync `RDSClient` has the same method.
